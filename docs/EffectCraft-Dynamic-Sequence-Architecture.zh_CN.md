# EffectCraft 动态透明序列架构

## 事实源与状态

现有 OpenSpec 的 EC-DM-005-SEQUENCE 持有本候选行为。独立技能源实现改动；在固定发行验收前，插件快照及运行时锁保留原发布身份。Art 和 Film 动态交接仍开放。

## 合同

公开计划接受 `exports: [{"format":"png-sequence"}]`，保留既有单 MP4 选项。工作流保存并重开 `project.ecproj`，调用固定原生 PNG 渲染器的 RGBA 通道。`rgba-sequence/sequence.json` 使用 `craft-image-sequence/v1`，记录零起点连续帧名、字节与还原 RGBA 摘要、尺寸、8 位通道、实际 alpha 极值、有理帧率和以帧为单位的持续时间。PNG 表示为非预乘 alpha；色彩空间标为未知，不宣称完整色彩保真。

```mermaid
flowchart LR
    P[已验证计划] --> N[原生合成保存并重开]
    N --> R[有界 RGBA 序列渲染]
    R --> V[CRC 与扫描结构 / 还原 alpha / 连续帧集合]
    V --> M[序列清单与可编辑工程交付]
    M --> F[Film 显式帧率导入：待完成]
```

## 失败与资源边界

缺帧、多余帧、链接、损坏、不同尺寸、非 RGBA8 或全不透明帧拒绝透明交付。原生执行前限制 10,000 帧及总解码 RGBA 512 MiB；PNG 文件结构及解压尺寸另有上限。逐帧派生物保留编辑损失报告；可编辑动画和文字保留在原生合成中。序列引用不包含私有临时路径。

## 原生修订

文字修订从摘要匹配的已有工程开始，保留源交付；比较独立徽标图层和透明度动画，零帧保持，后续文字变化帧必须不同。每项独立技能包含自己的安装资源，不读取兄弟技能。

## 验收与限制

[候选证据](evidence/dynamic-sequence-candidate-20261006.json)：单独复制导出技能、空运行时、默认公开下载安装的原生首用通过（14.833 秒）。Pillow 独立解码全部 12 帧并匹配还原 RGBA 摘要及实际 alpha 极值。四项完整性／损坏／资源测试及格式回归通过；默认回归 32 项通过、19 项门禁跳过。执行前后源技能及副本摘要保持。

此证据不证明 Film 动态导入、Art 依赖编排、新不可变插件安装、创作审阅或完整首版。既有 Film 原生导入使用默认媒体时间基，12 帧被缩为约 0.4 秒；该缺陷由另一维护补丁及原生回归门禁处理。
