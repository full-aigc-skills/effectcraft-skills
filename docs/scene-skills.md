# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `effectcraft-logo-reveal`：标志开场动效（标志入场、停留与收尾）
- `effectcraft-lower-thirds`：人物条与字幕条（姓名、职位与品牌标识）
- `effectcraft-kinetic-type`：文字节奏动效（标题和短文案动画）
- `effectcraft-social-loop`：社交循环动图（短循环动画与封面）
- `effectcraft-screen-composite`：画面合成（图层、遮罩与屏幕内容替换）
- `effectcraft-motion-export`：动效输出检查（合成时长、帧率与编码）
